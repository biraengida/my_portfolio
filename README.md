# Bira Engida - Portfolio Website

A simple, clean personal portfolio website for Bira Engida, a 15-year-old developer passionate about AI and cybersecurity.

## Tech Stack

- HTML
- CSS

## Features

- Clean and responsive design
- About section
- Tech stack overview
- Projects showcase (Port Scanner and Portfolio Website)
- Goals list
- Social links section
- Simple, readable layout

## File Structure

```

portfolio/
├── index.html
├── style.css
└── README.md

```

## How to Use

1. Download both `index.html` and `style.css`
2. Place them in the same folder
3. Open `index.html` in any web browser

## Customization

- Edit the text in `index.html` to update content
- Modify colors and spacing in `style.css`
- Add more projects by copying the project div
- Update social links with your actual profiles
